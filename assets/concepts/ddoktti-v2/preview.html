DDOKTTI / MOTION STUDY 03

걷고, 알리고, 아슬아슬 버티고.

새 알림 동작 + HTML 말풍선 미리보기 →

슬랙 알림을 포함한 7가지 동작. 걷기는 발 동작과 화면 이동을 함께, 낙하는 떨어지는 속도와 착지를 함께 확인합니다.

이미지를 불러오는 중…

01 / SLACK

슬랙 왔어요!

짧은 다리와 큰 머리 비율로 다시 그렸어요. 슬랙 카드를 들고 손을 흔들어요.

02 / WALK

짧은 다리로, 총총

걷는 동작은 유지하고 다리를 짧게 줄였어요. 작은 발걸음으로 화면을 왕복합니다.

03 / CALENDAR

곧 일정이 시작돼요

별도 시트로 다시 생성해 아래 행의 그림이 섞이지 않게 했습니다.

04 / STRETCH

잠깐 몸을 풀까요?

일하다가 잠깐, 똑띠와 함께 기지개를 켜요.

05 / TIMER

약속한 시간이 됐어요

시계와 함께 완료를 알리고 확인을 기다려요.

06 / ALMOST FALLING

어어… 휴, 살았다!

발을 헛디딤 → 버티기 → 중심 되찾기 → 안도. 떨어지지 않는 경로입니다.

07 / FALL & LAND

툭, 떨어져도 괜찮아

놓임 → 가속 낙하 → 웅크려 착지 → 다시 서기. 드래그해서 놓았을 때를 상상한 동작입니다.

애니메이션 검토용 페이지입니다. 실제 앱이나 알림 설정은 변경하지 않습니다. ‘한 단계씩’은 120ms 단위로 진행합니다.
새 PNG는 내장 이미지 생성 도구로 만들었으며, 캔버스는 프레임 표시·이동만 담당합니다. 원본 v1은 보관했습니다.
