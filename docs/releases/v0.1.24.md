# 똑띠왔어요 0.1.24

Slack 알림에 사진·동영상 미리보기를 더하고, 캐릭터 움직임을 더 부드럽게 다듬었습니다.

**사진 미리보기를 보려면 업데이트 후 설정 → Slack에서 "다시 연결"을 한 번 눌러 주세요.** 미리보기에 새 Slack 권한(파일 읽기)이 필요합니다. 다시 연결하기 전에도 알림은 그대로 오고, 미리보기만 빠집니다.

- 사진이나 동영상이 온 Slack 메시지는 말풍선에 작은 미리보기 이미지를 함께 보여 줍니다. 동영상은 대표 이미지를 보여 주며, 설정에서 "알림 내용 숨기기"를 켜면 미리보기도 숨깁니다.
- 글 없이 사진·동영상·파일만 온 메시지가 빈 말풍선으로 오던 문제를 고쳤습니다. 이제 "📷 사진", "🎬 동영상", "📎 파일: 견적서.pdf"처럼 보여 줍니다.
- 알림 말풍선의 간편 반응에 🙌를 더했습니다.
- 캐릭터가 걷거나 움직일 때 가끔 멈칫하거나 떨리던 문제를 고쳤습니다. 화면 주사율에 맞춰 그리고, 그리는 비용을 크게 줄였습니다(특히 Mac).
- 트랙패드를 탭만 해도 캐릭터 메뉴(두 손가락 탭)와 간지럼 반응(한 손가락 탭)이 동작합니다. 전에는 꾹 눌러야만 반응했습니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
