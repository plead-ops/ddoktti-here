# 똑띠왔어요 0.1.20

Slack 스레드 답글 알림을 더했습니다.

- 내가 시작했거나 답글을 단 스레드에 새 답글이 오면 멘션이 없어도 알려 줍니다. 설정의 Slack 필터에서 "내가 참여한 스레드의 답글"로 끌 수 있습니다. 판단에 쓰는 스레드 작성자 목록은 서버가 1분만 참조하고 저장하지 않습니다.
- 0.1.19의 변경(가만히 있을 때 고개 갸웃, 일정 알림 남은 시간, 5분 수면, 창 위 갇힘 탈출, 천장 투어, Slack에서 읽은 알림 자동 해제)이 모두 포함됩니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
