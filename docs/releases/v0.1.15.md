# 똑띠왔어요 0.1.15

캐릭터의 반응과 모니터 이동을 개선하고, 서비스 연결이 끊겼을 때의 안내를 정리했습니다.

- 새 산책을 시작할 때 방향을 다시 골라 한쪽으로 계속 이동하는 경향을 줄였습니다.
- 마우스 포인터를 따라갈 때 두 손을 들고 웃으며 달립니다. 실제 이동 거리와 발걸음을 맞춥니다.
- 캐릭터를 마우스로 살살 쓰다듬으면 좋아하는 표정으로 반응합니다.
- 높은 곳에서 떨어졌을 때 철푸덕 엎어진 뒤 일어나는 동작으로 바꿨습니다.
- 모니터 사이를 줄타고 이동할 때 주변 창 때문에 위치가 번갈아 바뀌는 문제를 수정했습니다.
- Windows에서 배율이 다른 모니터 사이를 이동할 때 캐릭터가 잘릴 수 있는 창 크기 처리 문제를 수정했습니다.
- Slack·Google 연결 장애는 짧은 말풍선으로 안내하고 설정에 연결 상태를 표시합니다. 자동으로 재시도하며, 인증이 만료된 경우에만 다시 연결하도록 안내합니다.
- 서비스 연결이 끊겨도 캐릭터와 로컬 타이머는 계속 동작합니다. 장애 안내를 캐릭터에 상시 표시하지 않습니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
