# 똑띠왔어요 0.1.22

Windows 표시 문제와 Slack 알림 세부 동작을 다듬었습니다.

- Windows에서 화면 위에서 줄을 타고 내려올 때 줄만 보이고 캐릭터가 착지 뒤에야 보이던 문제에 대응했습니다. 같은 증상이 계속되면 설정의 진단 전송을 보내 주세요. 창 크기 이상이 기록되어 원인을 찾는 데 쓰입니다.
- 스레드 답글 안에서 내가 속한 그룹이 멘션되면 멘션 알림으로 옵니다.
- Slack에서 읽은 알림 자동 해제가 스레드 밖 메시지에만 적용되도록 바로잡았습니다. 스레드 답글은 Slack이 따로 읽음을 관리해 잘못 닫히는 경우가 있었습니다.
- DM 알림에서 간편 답글을 보내면 대화에 바로 올라갑니다(채널 메시지는 스레드 답글로 올라갑니다).

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
