# 똑띠왔어요 0.1.19

가만히 있을 때와 알림 중에도 살아 있고, 창 위에 갇히지 않게 다듬었습니다.

- 가만히 서 있을 때 고개를 좌우로 갸웃하고 가끔 눈을 깜빡입니다. 새 그림 4장은 기본 자세와 비율·선 굵기·재킷 밑단까지 맞췄습니다.
- 알림 말풍선이 떠 있는 동안 캐릭터가 멈춰 있지 않고 두 가지 자세를 번갈아 보여 줍니다.
- 일정 알림이 "곧"이 아니라 "1시간 뒤 일정이 시작돼요"처럼 남은 시간을 정확히 말하고, 말풍선이 떠 있는 동안 시간이 줄어듭니다. 시작 시각과 종료 시각도 함께 보입니다. 알림 내용 숨기기를 켠 경우 시각은 표시하지 않습니다.
- 5분 넘게 입력이 없으면 바로 이불을 덮고 잡니다. 돌아오면 반기고, 30분 이상 비웠다면 더 반가워합니다.
- 창 위에서 내려오지 않던 경우를 고쳤습니다. 내려오고 싶을 땐 다시 올라가지 않고, 줄도 짧은 점프도 없으면 발판 끝까지 걸어가 바로 아래 창이나 바닥으로 뛰어내립니다. 한쪽 끝에서 안 되면 반대쪽 끝을 시도합니다.
- 창을 최대화했을 때의 천장 투어는 반대편 끝까지 가로지르며 중간중간 멈춰 구경하고, 옆면 빼꼼은 두 번 내밉니다.
- 줄을 타고 올라가거나 내려온 뒤의 어색한 착지 표정을 없앴습니다. 발판 창이 닫혀 떨어졌을 때의 말풍선도 없앴습니다.
- 캐릭터 동작에 겹쳐 있던 위아래 흔들림을 모두 뺐습니다. 그림 전환만으로 움직입니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
