# 똑띠왔어요 0.1.10

Windows와 macOS에서 사용할 수 있는 데스크톱 캐릭터 앱입니다.

- 캐릭터의 자율 산책, 달리기, 휴식과 다양한 감정 표현, 창 위로 올라가기와 줄 타기
- Slack 계정 연결을 통한 DM·공개 채널 멘션 알림, Slack 사용 중 알림 생략
- Windows Slack PWA·브라우저 지원 및 Mac Slack 앱 감지
- Google Calendar의 주최·참석·응답 전 초대·개인 일정 알림과 중복 제거
- 타이머, 스트레칭 안내, 클릭 간지럽히기와 드래그 이동
- 네이티브 캐릭터 렌더링, SVG 동작과 개선된 말풍선
- 혼합 배율 다중 모니터 이동 및 입력 감시 교착 상태 수정
- Windows x64 설치 파일과 Apple Silicon·Intel 공용 Mac DMG, 플랫폼별 서명된 자동 업데이트 패키지

기존 Windows 알림 감지 방식은 제거되었습니다. 업데이트 후 설정에서 Slack과 Google 계정을 연결해 주세요.

Windows는 `x64-setup.exe`, Mac은 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다.
