# 똑띠왔어요 0.1.14

캐릭터가 화면과 창 위에서 더 자연스럽게 움직이고, 짧은 반응과 일정 알림을 더 잘 알아볼 수 있도록 개선했습니다.

- 캐릭터 크기를 최대 5배까지 조절하고, 메인 모니터에서만 활동할지 다른 모니터로도 이동할지 선택할 수 있습니다.
- 비활성 창과 앞뒤로 겹친 창의 노출된 가장자리를 인식합니다. 최대화·분할 화면에서는 줄타기, 상단 이동과 빼꼼 내다보기를 하며 놀이 사이에 충분히 쉽니다.
- 가까운 마우스 포인터를 달려서 따라가고 멈춰 바라봅니다. 창 끝에서는 주춤한 뒤 돌아서거나 떨어지는 동작으로 이어집니다.
- 상단 손 위치, 이동 방향, 등반 앵커의 흔들림을 보정하고 이동 갱신을 60Hz 목표로 개선했습니다.
- 높은 곳에서 떨어졌을 때 아파하는 동작과 착지·하품 이미지를 새 원화에서 벡터로 제작했습니다. 정장 구분선과 외곽선도 정리했습니다.
- 간지럽힘·타이머 설정 확인을 작은 말풍선으로 보여주며, 오래 간지럽히면 “이제 그만!” 하고 반응합니다. 알림 말풍선은 처음 나타날 때 확대·축소하고 색상으로 점멸합니다.
- Google Calendar 일정 시작 전 알림을 여러 시점에 설정할 수 있습니다. 시작 시각 알림, 중복 방지와 뒤늦게 깨어났을 때의 알림 정리도 지원합니다.
- 처음 설정을 마친 뒤에는 앱을 켤 때 설정 창이 자동으로 열리지 않습니다. 계정 연결 안내 페이지 디자인을 개선했습니다.
- Windows 신규 설치·현행 버전 재설치에서는 불필요한 구버전 정리용 PowerShell 실행을 건너뜁니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.

### 첫 실행 계정 연결

- Slack·Google 연결 버튼을 녹색으로 강조했습니다.
- 시작 버튼은 기본 아웃라인이며 두 계정이 모두 연결되면 녹색으로 바뀝니다. 계정 연결은 나중에도 가능합니다.
