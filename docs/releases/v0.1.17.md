# 똑띠왔어요 0.1.17

창 위로 올라간 캐릭터가 스스로 내려오도록 했습니다.

- 창 위에 오래 머물수록, 높이 올라가 있을수록 내려오고 싶어 합니다. 올라간 지 30초쯤부터 조금씩, 2분이 지나면 대부분 내려오는 쪽을 고릅니다. 바닥에 서면 다시 처음부터 올라갈 궁리를 합니다.
- 바닥이나 아래 창이 가까우면 창 모서리에서 폴짝 뛰어내립니다. 일부러 뛰는 것이라 철푸덕 넘어지지 않습니다.
- 높이 차가 크면 창 모서리까지 걸어가 줄을 타고 옆면을 쭉 내려옵니다. 내려오는 중에 창을 움직이면 따라오고, 창을 닫으면 떨어집니다.
- 모션 갤러리와 창 위 산책 미리보기에 "모서리에서 줄 타기", "줄 타고 내려오기" 동작을 추가했습니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
