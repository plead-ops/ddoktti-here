# 똑띠왔어요 0.1.16

macOS 다중 모니터 환경의 표시 문제를 수정하고, 모니터 사이 이동이 실제로 시작되도록 고쳤습니다.

- macOS에서 최대화 창을 줄타고 올라가 매달릴 때 줄과 캐릭터 윗부분이 잘리던 문제를 수정했습니다. 캐릭터 창을 메뉴 막대 위에도 그릴 수 있는 창 레벨로 바꾸고, 놀이 중 지우기 범위를 작업영역이 아닌 실제 화면 경계로 맞췄습니다.
- macOS에서 배율이 다른 두 모니터에 캐릭터가 걸칠 때(빼꼼, 점프·줄타기 이동) 빠르게 깜빡이던 문제를 수정했습니다. 캐릭터 창은 항상 한 모니터 안에만 두고, 이웃 모니터로 넘어가는 부분은 보조 창이 그 모니터의 배율로 그립니다.
- 활동 범위를 "모든 모니터"로 설정해도 다른 모니터로 거의 넘어가지 않던 문제를 수정했습니다. 바닥 끝에 닿아 돌아서기 전에 이동을 시작합니다.
- 슬랙 멘션 알림에서 멘션 대상이 "@멤버"로만 표시되던 문제를 중계 서버에서 수정했습니다. 실제 이름이 표시됩니다.
- 드래그할 때 포인터가 안테나 끝을 잡습니다. 몸은 진자처럼 흔들리고, 빠르게 휘두르면 안테나 끝을 축으로 한 바퀴 돕니다.
- 잡힌 채 세게 흔들면 눈이 빙글빙글 도는 어지러움 표정이 나오고, 잠잠해지면 돌아옵니다.
- 쓰다듬기 반응을 볼이 발그레해지며 눈을 감는 표정으로 바꿨습니다.
- 포인터를 따라 달릴 때 신발 색이 바지와 같은 색으로 보이던 문제를 수정했습니다.
- 우클릭 메뉴를 정리했습니다. 우상단 X로 닫고, 타이머가 돌고 있으면 남은 시간과 일시정지·중지 버튼을 보여 주며, 알림 끄기 문구를 "30분 동안 알림 끄기 / 알림 다시 켜기"로 바꿨습니다.
- 진단용으로 `DDOKTTI_TRACE=1` 환경변수를 켜면 프레임 좌표와 처리 시간을 로그로 남깁니다. 메시지 내용은 기록하지 않습니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
