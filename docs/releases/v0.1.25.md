# 똑띠왔어요 0.1.25

첫 설정을 마친 뒤 캐릭터가 보이지 않던 문제를 고치고, 잠자기 동작을 다듬었습니다.

- 첫 설정 화면을 마치면 캐릭터가 바로 화면에 나타납니다. 전에는 "항상 함께하기"가 꺼진 채 저장되는 경우가 있어 알림이 올 때만 보였습니다. 이미 "필요할 때 만나기"를 고른 분의 설정은 그대로 유지됩니다.
- Windows에서 작업표시줄을 자동 숨김으로 쓰면 최대화한 창을 전체 화면으로 잘못 보고 캐릭터를 숨기던 문제를 고쳤습니다.
- 설정 화면에서 전체 화면이나 발표 중으로 감지되어 캐릭터가 숨겨진 상태를 알려 줍니다. 진단 리포트에도 표시 상태가 들어갑니다.
- 첫 설정의 연결 단계에서 Slack과 Google Calendar를 모두 연결하면 좋다는 안내를 보여 줍니다. 연결하지 않아도 시작할 수 있고, 첫 설정을 마치지 않으면 다음에 켤 때 다시 보여 줍니다.
- 자리를 비우면 5분 뒤에 잠들고, 잠든 동안에는 자리에서 일어나지 않습니다. 돌아왔을 때 인사를 놓치면 그때 일어납니다.

Windows는 `x64-setup.exe`, Mac은 Apple Silicon·Intel 공용 `universal.dmg`를 다운로드하세요. `.app.tar.gz`와 `.sig`, `latest.json`은 자동 업데이트용입니다. 기존 계정 연결과 설정은 유지됩니다.
